Dos Viajeros

Herramienta personal para que un grupo privado de amigos alterne el alojamiento de su partida de Minecraft.

La aplicación de escritorio descarga la última partida guardada, reserva el turno de anfitrión y, al apagar el servidor, sube una copia verificada a una carpeta privada de Google Drive. GitHub conserva la configuración y el estado del turno.

No es un servicio de alojamiento ni tiene suscripciones. El servidor se ejecuta en la PC del anfitrión.

Política de privacidad y uso de datos de Google
